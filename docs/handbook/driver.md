# 司機（driver）作業手冊

本文件描述司機端的日常操作流程（怎麼做）；任務/車輛/站點移動的規則與一致性以 `docs/modules/operations.md` 為準。

## 角色目標

- 依任務清單完成取件/配送/交接
- 在相鄰節點間移動車輛並同步位置
- 遇到無法正常流轉時申報異常

## 介面概覽（/driver/map）

司機工作主要在地圖頁完成，畫面右側是工作面板：

- 司機資訊：貨車編號、目前位置、車上包裹數、最後同步時間（必要時會顯示「導航至」目標）
- 任務清單：所有被指派的任務都在同一份清單中；當車輛移動到不同節點時，清單中每個任務的「功能」會依情況改變（例如：正在前往 / 收款 / 取貨 / 卸貨）

工作面板可收合，讓地圖視野更大；任務多時，清單會在卡片內滾動，不會把整個版面撐高。

## 任務清單怎麼看

每筆任務代表「包裹從某地點送到另一個地點」的其中一段（segment）。任務清單會把你目前需要處理的段落列出來。

任務項目分兩種來源：

- 指派任務（assigned）：一定要完成的任務段落
- 可搶單/可接手（handoff）：只會在你「剛好位於可交接節點」時出現；通常是 HUB/REG 作為起點且尚未被其他司機接手的任務

任務項目點開後會看到更完整的細節（路線、寄件者/收件者、尺寸/重量、客服指示、提示），並在裡面執行操作。

## 功能按鈕（核心行為）

每個任務固定有兩個操作：

- 功能：系統依任務狀態與你目前所在節點，推斷「下一步最該做什麼」
- 申報異常：遇到無法正常完成（客戶拒收、貨件破損、找不到收件人等）時用

功能按鈕可能出現的行為：

- 正在前往：表示你已接手/被指派此任務，但尚未完成下一個節點的作業；點擊後會把任務標記為在途，並在地圖上引導你前往下一個目的地
- 收款：只有在「客戶尚未付款」且需要現金處理時才會出現；點擊前請務必確認已向客戶收款
- 取貨：你已到達任務起點（例如：住家/配送站）且該包裹尚未裝載到車上
- 卸貨：你已到達任務終點且該包裹已在車上，準備卸貨完成該段任務
- 搶單：只會出現在可交接節點的任務（handoff）；點擊後將任務接手到自己名下

注意：地圖頁不再特別提供「抵達」按鈕；對司機而言，能做收款/取貨/卸貨就代表已到達並可完成該步驟。

## 操作流程（建議）

1. 取得自己的車輛狀態（位置、車碼）
2. 打開任務清單，確認目前有哪些指派任務
3. 針對要處理的任務，點開任務項目 → 點「功能」（通常會是「正在前往」）啟動引導
4. 依照引導在地圖上移動車輛（僅能移動到相鄰節點）
5. 到達目的地後，回到任務項目 → 點「功能」完成當前節點的作業（收款/取貨/卸貨）
6. 若經過可交接節點且出現「搶單」，可視情況接手任務
7. 若遇到無法完成的狀況，點「申報異常」並填寫原因與說明

## 任務為空時怎麼辦

如果任務清單顯示「目前沒有任務」，可以：

- 點「重新整理」確認是否有新任務
- 移動到其他節點（系統可能在特定節點才會出現可交接任務）
- 若仍長時間沒有任務，請回報客服/管理者確認派工狀態
